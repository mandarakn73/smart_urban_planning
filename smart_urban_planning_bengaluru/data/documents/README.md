# Bengaluru planning knowledge base

Place only verified/approved planning documents here, preferably official Bengaluru/BDA/GBA/BBMP sources.

Recommended sources for the prototype:
- Revised Master Plan / Master Plan documents applicable to the study area
- Zonal Regulations
- Building bye-laws / development control rules
- FAR / setback / parking provisions
- Fire and life-safety requirements
- Environmental and water-body protection rules where applicable

Do not place research papers here as if they were legal/planning rules. The RAG layer returns document name and page metadata so retrieved evidence can be cited in the final report.

After adding documents, restart the API or call `POST /rag/reload`.
